# Пояснення коду та роботи програм

## Загальний опис

Два Python-скрипти (`shop_db.py` та `library_db.py`) реалізують роботу з базами даних SQLite. Вони демонструють основні операції з БД: створення таблиць, вставка даних, оновлення, видалення та виконання запитів.

---

## 1. Скрипт `shop_db.py` — База даних магазину

### Структура даних

**Таблиця `products`:**
```
id (INTEGER, PRIMARY KEY) — унікальний ідентифікатор товару (автоматично інкрементується)
name (TEXT) — назва товару
category (TEXT) — категорія товару
price (REAL) — ціна товару
quantity (INTEGER) — кількість товару на складі
```

### Як працює скрипт:

#### 1. Підключення до БД
```python
conn = sqlite3.connect('shop.db')
cursor = conn.cursor()
```
- `sqlite3.connect()` — з'єднується з базою даних (якщо файлу немає, він створюється)
- `cursor()` — створює об'єкт для виконання SQL-команд

#### 2. Створення таблиці
```python
cursor.execute('''
    CREATE TABLE IF NOT EXISTS products (...)
''')
conn.commit()
```
- `CREATE TABLE IF NOT EXISTS` — створює таблицю, якщо її ще немає
- `PRIMARY KEY AUTOINCREMENT` — автоматично генерує ID для кожного запису
- `conn.commit()` — зберігає зміни в БД

#### 3. Вставка товарів
```python
products = [
    ('Ноутбук', 'Електроніка', 15000, 5),
    ...
]
cursor.executemany('''
    INSERT INTO products (name, category, price, quantity)
    VALUES (?, ?, ?, ?)
''', products)
conn.commit()
```
- `executemany()` — вставляє кілька записів одночасно
- `?` — плейсхолдери для безпеки від SQL-ін'єкцій
- Список `products` містить кортежі: (назва, категорія, ціна, кількість)

#### 4. Виведення всіх товарів
```python
cursor.execute('SELECT * FROM products')
for row in cursor.fetchall():
    print(...)
```
- `SELECT * FROM products` — отримує всі записи з таблиці
- `fetchall()` — повертає список усіх рядків результату
- `fetchone()` — повертає один рядок

#### 5. Фільтрація товарів дорожчих за 1000
```python
cursor.execute('SELECT * FROM products WHERE price > 1000 ORDER BY price DESC')
```
- `WHERE price > 1000` — умова: вибирає тільки товари з ціною більше 1000
- `ORDER BY price DESC` — сортує за ціною від більшої до меншої (DESC = descending)
- `ASC` — від меншої до більшої (ascending)

#### 6. Вибір товарів з конкретної категорії
```python
cursor.execute('SELECT * FROM products WHERE category = ? ORDER BY price DESC', ('Електроніка',))
```
- Вибирає товари з категорії "Електроніка"
- Другий аргумент `('Електроніка',)` — значення для плейсхолдера

#### 7. Оновлення даних
```python
cursor.execute('UPDATE products SET price = 300 WHERE name = ?', ('Миша',))
conn.commit()
```
- `UPDATE` — змінює існуючі дані
- `SET price = 300` — нове значення
- `WHERE name = ?` — умова: змінювати тільки запис з назвою "Миша"

#### 8. Видалення даних
```python
cursor.execute('DELETE FROM products WHERE name = ?', ('Вентилятор',))
conn.commit()
```
- `DELETE FROM` — видаляє запис
- `WHERE name = ?` — видаляти тільки запис з назвою "Вентилятор"

#### 9. Статистичні функції
```python
cursor.execute('SELECT COUNT(*) FROM products')
count = cursor.fetchone()[0]
```
- `COUNT(*)` — кількість рядків
- `AVG(price)` — середня ціна
- `MAX(price)` — найбільше значення
- `MIN(price)` — найменше значення

## 2. Скрипт `library_db.py` — База даних бібліотеки

### Структура даних

**Таблиця `authors`:**
```
id (INTEGER, PRIMARY KEY) — унікальний ідентифікатор автора
name (TEXT) — ім'я автора
country (TEXT) — країна, звідки автор
```

**Таблиця `books`:**
```
id (INTEGER, PRIMARY KEY) — унікальний ідентифікатор книги
title (TEXT) — назва книги
year (INTEGER) — рік видання
pages (INTEGER) — кількість сторінок
author_id (INTEGER, FOREIGN KEY) — посилання на автора з таблиці authors
```

### Зв'язок між таблицями

```python
FOREIGN KEY (author_id) REFERENCES authors(id)
```
- **FOREIGN KEY** — зовнішній ключ, пов'язує две таблиці
- `author_id` в таблиці `books` вказує на `id` в таблиці `authors`
- Це забезпечує **посилання на автора** для кожної книги

### Як працює скрипт:

#### 1. Вставка авторів
```python
authors = [
    ('Леонід Українка', 'Україна'),
    ('Тарас Шевченко', 'Україна'),
    ...
]
cursor.executemany('INSERT INTO authors (name, country) VALUES (?, ?)', authors)
conn.commit()
```
- Вставляє 6 авторів із їх країнами

#### 2. Вставка книг
```python
books = [
    ('Лісова пісня', 1911, 120, 1),  # 1 — ID автора Леоніда Українки
    ('Мертві душі', 1842, 512, 2),   # 2 — ID автора Тараса Шевченка
    ...
]
cursor.executemany('''
    INSERT INTO books (title, year, pages, author_id)
    VALUES (?, ?, ?, ?)
''', books)
conn.commit()
```
- Кожна книга пов'язана з автором через `author_id`

#### 3. Об'єднання таблиць (JOIN)
```python
cursor.execute('''
    SELECT b.title, b.year, b.pages, a.name, a.country
    FROM books b
    JOIN authors a ON b.author_id = a.id
    ORDER BY b.year
''')
```
- `FROM books b` — таблиця books з псевдонімом `b`
- `JOIN authors a ON b.author_id = a.id` — з'єднує з таблицею authors
  - Умова: `author_id` з books повинна дорівнювати `id` з authors
- `ORDER BY b.year` — сортує за роком видання
- Результат: кожна книга + дані про її автора

#### 4. Книги одного автора
```python
cursor.execute('''
    SELECT b.title, b.year, b.pages, a.name
    FROM books b
    JOIN authors a ON b.author_id = a.id
    WHERE a.name = ?
    ORDER BY b.year
''', ('Леонід Українка',))
```
- `WHERE a.name = ?` — додає умову: вибирати тільки книги цього автора

#### 5. Групування і агрегація
```python
cursor.execute('''
    SELECT a.name, a.country, COUNT(b.id) as book_count
    FROM authors a
    LEFT JOIN books b ON a.id = b.author_id
    GROUP BY a.id, a.name, a.country
    ORDER BY book_count DESC
''')
```
- `LEFT JOIN` — з'єднання (повертає всіх авторів, навіть без книг)
- `GROUP BY` — групує результати за автором
- `COUNT(b.id)` — рахує кількість книг для кожного автора
- `ORDER BY book_count DESC` — сортує від більшої кількості до меншої

#### 6. Середня кількість сторінок
```python
cursor.execute('''
    SELECT a.name, COUNT(b.id) as book_count, AVG(b.pages) as avg_pages
    FROM authors a
    LEFT JOIN books b ON a.id = b.author_id
    GROUP BY a.id, a.name
    ORDER BY avg_pages DESC
''')
```
- `AVG(b.pages)` — середнє значення кількості сторінок для кожного автора

#### 7. Автор з найбільшою кількістю книг
```python
cursor.execute('''
    SELECT a.name, a.country, COUNT(b.id) as book_count
    FROM authors a
    LEFT JOIN books b ON a.id = b.author_id
    GROUP BY a.id, a.name, a.country
    ORDER BY book_count DESC
    LIMIT 1
''')
```
- `LIMIT 1` — повертає тільки перший рядок (з найбільшою кількістю)

## Основні SQL операції

| Операція | Опис | Приклад |
|----------|------|---------|
| **SELECT** | Вибір даних | `SELECT * FROM products` |
| **WHERE** | Фільтрація | `WHERE price > 1000` |
| **ORDER BY** | Сортування | `ORDER BY price DESC` |
| **INSERT** | Вставка даних | `INSERT INTO products VALUES (...)` |
| **UPDATE** | Оновлення | `UPDATE products SET price = 300` |
| **DELETE** | Видалення | `DELETE FROM products WHERE id = 1` |
| **COUNT()** | Кількість рядків | `SELECT COUNT(*) FROM products` |
| **AVG()** | Середнє значення | `SELECT AVG(price) FROM products` |
| **MAX()** | Максимум | `SELECT MAX(price) FROM products` |
| **MIN()** | Мінімум | `SELECT MIN(price) FROM products` |
| **JOIN** | З'єднання таблиць | `FROM books JOIN authors ON ...` |
| **GROUP BY** | Групування | `GROUP BY author_id` |
| **LIMIT** | Обмеження результатів | `LIMIT 10` |

## Ключові концепції

### 1. **SQLite**
- Легка база даних без сервера
- Файл `.db` містить всю базу
- Ідеальна для навчання та малих проектів

### 2. **Модуль sqlite3**
- Вбудований в Python
- Дозволяє роботу з SQLite БД
```python
import sqlite3
```

### 3. **Транзакції**
- `conn.commit()` — зберігає зміни
- Без `commit()` зміни не будуть збережені

### 4. **Безпека від SQL-ін'єкцій**
```python
# ✓ Безпечно
cursor.execute('SELECT * FROM products WHERE name = ?', (name,))

# ✗ Небезпечно
cursor.execute(f'SELECT * FROM products WHERE name = {name}')
```
- Завжди використовуйте `?` плейсхолдери

### 5. **Зовнішні ключі (Foreign Keys)**
- Пов'язують дані в різних таблицях
- Забезпечують цілісність даних
- У `books` таблиці `author_id` вказує на `authors` таблицю

## Приклади запитів

### Вибір даних:
```python
# Усі товари
SELECT * FROM products

# Товари дорожчі за 1000
SELECT * FROM products WHERE price > 1000

# Сортування за ціною (від більшої до меншої)
SELECT * FROM products ORDER BY price DESC
```

### Зміни даних:
```python
# Оновлення ціни
UPDATE products SET price = 300 WHERE name = 'Миша'

# Видалення товару
DELETE FROM products WHERE name = 'Вентилятор'

# Вставка нового товару
INSERT INTO products (name, category, price, quantity) 
VALUES ('Нова миша', 'Електроніка', 400, 20)
```

### Статистика:
```python
# Кількість товарів
SELECT COUNT(*) FROM products

# Середня ціна
SELECT AVG(price) FROM products

# Найдорожчий товар
SELECT MAX(price), name FROM products

# Найдешевший товар
SELECT MIN(price), name FROM products
```

### Об'єднання таблиць:
```python
# Всі книги з іменами авторів
SELECT b.title, a.name 
FROM books b 
JOIN authors a ON b.author_id = a.id

# Кількість книг у кожного автора
SELECT a.name, COUNT(b.id) as book_count
FROM authors a
LEFT JOIN books b ON a.id = b.author_id
GROUP BY a.id, a.name
```
