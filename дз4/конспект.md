# Пояснення коду books_parser.py

## Загальне призначення програми

Ця програма автоматично збирає інформацію про книги із сайту https://books.toscrape.com/.

Програма:

* відкриває сторінки каталогу книг;
* знаходить усі книги на сторінці;
* отримує назву книги;
* отримує ціну;
* отримує рейтинг;
* отримує інформацію про наявність;
* отримує посилання на книгу;
* переходить на наступні сторінки;
* збирає всі книги в один список;
* обчислює статистику;
* зберігає результати у CSV-файл.

---

# Імпорт бібліотек

```python
import csv
```

Імпортується стандартна бібліотека Python для роботи з CSV-файлами.

CSV (Comma-Separated Values) — це текстовий файл, у якому дані зберігаються у вигляді таблиці.

Приклад:

```csv
title,price,rating
Book A,10.5,4
Book B,15.0,5
```

---

```python
import requests
```

Бібліотека `requests` використовується для надсилання HTTP-запитів до сайтів.

Саме через неї програма завантажує HTML-код сторінки.

Наприклад:

```python
requests.get("https://books.toscrape.com")
```

надсилає запит до сайту.

---

```python
from bs4 import BeautifulSoup
```

Імпортується клас `BeautifulSoup`.

Він використовується для аналізу HTML-коду.

BeautifulSoup дозволяє знаходити теги:

```html
<h1>Hello</h1>
```

або

```html
<a href="page.html">Link</a>
```

та отримувати з них інформацію.

---

```python
from urllib.parse import urljoin
```

Імпортується функція `urljoin`.

Вона використовується для створення повних посилань.

Наприклад:

```python
urljoin(
    "https://books.toscrape.com/catalogue/",
    "book_1/index.html"
)
```

дасть:

```text
https://books.toscrape.com/catalogue/book_1/index.html
```

---

```python
from collections import Counter
```

Імпортується клас `Counter`.

Він рахує кількість однакових елементів.

Наприклад:

```python
Counter([1,1,2,3,3,3])
```

результат:

```python
{1:2, 2:1, 3:3}
```

Тобто:

* число 1 зустрілося 2 рази;
* число 2 зустрілося 1 раз;
* число 3 зустрілося 3 рази.
