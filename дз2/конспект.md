
# Пояснення коду моделювання проходження глядачів

## Загальна ідея програми

Ця програма моделює ситуацію, коли глядачі проходять через турнікети перед початком події.

Потрібно знайти мінімальний час, за який наш глядач має прийти раніше, щоб з імовірністю не менше `0.9` встигнути пройти через турнікет до моменту `T`.

Програма використовує метод Монте-Карло: багато разів випадково моделює прихід глядачів і рахує, у скількох випадках наш глядач встиг.

---

# Імпорт бібліотеки

```python
import random
```

Підключається бібліотека `random`.

Вона потрібна для генерації випадкових чисел.

У цьому коді вона використовується для:

* випадкового часу приходу інших глядачів;
* випадкового часу проходження через турнікет.

---

# Клас Spectator

```python
class Spectator:
```

Створюється клас `Spectator`.

Клас описує одного глядача.

---

```python
def __init__(self, arrival, target=False):
```

Це конструктор класу.

Він автоматично викликається, коли створюється новий глядач.

Параметри:

* `arrival` — час приходу глядача;
* `target` — чи є цей глядач нашим спеціальним глядачем.

За замовчуванням:

```python
target=False
```

тобто звичайний глядач.

---

```python
self.arrival = arrival
```

У поле об'єкта `arrival` записується час приходу глядача.

Наприклад, якщо глядач прийшов у момент `12.5`, то:

```python
self.arrival = 12.5
```

---

```python
self.target = target
```

У поле `target` записується, чи є цей глядач нашим.

Якщо:

```python
target=True
```

то це наш глядач.

Якщо:

```python
target=False
```

то це інший випадковий глядач.

---

# Функція one_simulation

```python
def one_simulation(N, m, T, t1, x):
```

Ця функція проводить одну симуляцію.

Вона один раз моделює всю ситуацію з чергами і повертає:

```python
True
```

якщо наш глядач встиг пройти до часу `T`, або

```python
False
```

якщо не встиг.

Параметри:

* `N` — загальна кількість глядачів;
* `m` — кількість турнікетів;
* `T` — час до початку події;
* `t1` — максимальний час проходження одного глядача через турнікет;
* `x` — за скільки часу до початку прийшов наш глядач.

---

```python
spectators = []
```

Створюється порожній список глядачів.

У нього будуть додаватися всі глядачі: наш і випадкові інші.

---

```python
spectators.append(Spectator(T - x, True))
```

Додається наш глядач.

Його час приходу:

```python
T - x
```

Наприклад, якщо:

```python
T = 60
x = 10
```

то наш глядач прийде у момент:

```python
60 - 10 = 50
```

Тобто за 10 одиниць часу до кінцевого моменту `T`.

Другий параметр:

```python
True
```

означає, що це саме наш глядач.

---

```python
for _ in range(N - 1):
```

Цикл створює інших глядачів.

Чому `N - 1`?

Бо один глядач уже доданий — це наш глядач.

Якщо всього `N = 100`, то інших треба створити:

```python
100 - 1 = 99
```

---

```python
arrival_time = random.uniform(0, T)
```

Генерується випадковий час приходу іншого глядача.

Функція:

```python
random.uniform(0, T)
```

повертає випадкове число від `0` до `T`.

Тобто кожен інший глядач може прийти у будь-який момент до часу `T`.

---

```python
spectators.append(Spectator(arrival_time))
```

Створюється звичайний глядач і додається до списку.

Тут не вказано `target=True`, тому за замовчуванням:

```python
target=False
```

Це означає, що це не наш глядач.

---

```python
spectators.sort(key=lambda s: s.arrival)
```

Список глядачів сортується за часом приходу.

Тобто той, хто прийшов раніше, буде оброблятися раніше.

`lambda s: s.arrival` означає:

```text
для кожного глядача s взяти його час приходу arrival
```

Саме за цим значенням і виконується сортування.

---

```python
turnstiles = [0.0] * m
```

Створюється список турнікетів.

Кожен елемент списку показує, коли відповідний турнікет звільниться.

Наприклад, якщо:

```python
m = 3
```

то буде:

```python
[0.0, 0.0, 0.0]
```

Це означає, що всі три турнікети на початку вільні з моменту `0`.

---

```python
for s in spectators:
```

Цикл проходить по всіх глядачах у порядку їхнього приходу.

Змінна `s` — це один поточний глядач.

---

```python
best = turnstiles.index(min(turnstiles))
```

Знаходиться турнікет, який звільниться найраніше.

Розберемо:

```python
min(turnstiles)
```

знаходить найменший час звільнення серед усіх турнікетів.

```python
turnstiles.index(...)
```

знаходить номер турнікета з таким часом.

Наприклад:

```python
turnstiles = [5.0, 2.0, 7.0]
```

```python
min(turnstiles)
```

дає:

```python
2.0
```

А:

```python
turnstiles.index(2.0)
```

дає:

```python
1
```

Тобто найкращий турнікет має індекс `1`.

---

```python
start_time = max(s.arrival, turnstiles[best])
```

Визначається момент, коли глядач реально почне проходити через турнікет.

Тут є два варіанти:

1. Якщо глядач прийшов пізніше, ніж турнікет звільнився, він починає одразу.
2. Якщо турнікет ще зайнятий, глядач чекає.

Тому береться максимум із двох значень:

* `s.arrival` — коли глядач прийшов;
* `turnstiles[best]` — коли найкращий турнікет звільниться.

---

```python
service_time = random.uniform(1, t1)
```

Генерується випадковий час проходження через турнікет.

Він лежить у межах від `1` до `t1`.

Наприклад, якщо:

```python
t1 = 5
```

то час проходження може бути:

```text
1.2, 3.7, 4.9
```

і так далі.

---

```python
finish_time = start_time + service_time
```

Обчислюється час завершення проходження.

Тобто:

```text
час завершення = час початку + час проходження
```

Наприклад:

```python
start_time = 20
service_time = 3
```

тоді:

```python
finish_time = 23
```

---

```python
turnstiles[best] = finish_time
```

Оновлюється час зайнятості турнікета.

Якщо глядач завершив проходження у момент `23`, то цей турнікет буде зайнятий до `23`.

---

```python
if s.target:
```

Перевіряється, чи поточний глядач є нашим.

Якщо `s.target == True`, то це наш глядач.

---

```python
return finish_time <= T
```

Якщо це наш глядач, функція одразу повертає результат.

Умова:

```python
finish_time <= T
```

перевіряє, чи встиг він пройти до моменту `T`.

Якщо встиг — повертається:

```python
True
```

Якщо ні — повертається:

```python
False
```

---

```python
return False
```

Цей рядок спрацює лише у запасному випадку.

Наприклад, якщо наш глядач чомусь не був знайдений у списку.

У нормальній роботі програми до цього рядка майже ніколи не доходить.

---

# Функція probability

```python
def probability(N, m, T, t1, x, experiments=10000):
```

Ця функція оцінює ймовірність того, що наш глядач встигне пройти.

Вона запускає багато симуляцій і рахує частку успішних.

Параметр:

```python
experiments=10000
```

означає, що за замовчуванням буде виконано 10000 експериментів.

---

```python
success = 0
```

Лічильник успішних симуляцій.

Спочатку успіхів немає.

---

```python
for _ in range(experiments):
```

Цикл виконується `experiments` разів.

Якщо `experiments = 10000`, то буде 10000 симуляцій.

---

```python
if one_simulation(N, m, T, t1, x):
```

Запускається одна симуляція.

Якщо вона повернула `True`, це означає, що наш глядач встиг.

---

```python
success += 1
```

Кількість успіхів збільшується на 1.

---

```python
return success / experiments
```

Повертається частка успішних симуляцій.

Наприклад:

```python
success = 9000
experiments = 10000
```

тоді:

```python
success / experiments = 0.9
```

Тобто ймовірність дорівнює 90%.

---

# Функція find_min_time

```python
def find_min_time(N, m, T, t1):
```

Ця функція шукає мінімальне значення `x`.

Тобто мінімальний час, за який наш глядач має прийти раніше, щоб імовірність встигнути була не менше `0.9`.

---

```python
left = 0
right = T
```

Задаються межі пошуку.

```python
left = 0
```

означає, що глядач приходить рівно в момент `T`.

```python
right = T
```

означає, що глядач приходить у момент `0`, тобто максимально рано.

---

```python
for _ in range(40):
```

Виконується 40 кроків бінарного пошуку.

Бінарний пошук поступово звужує проміжок, у якому знаходиться відповідь.

40 кроків дають дуже високу точність.

---

```python
mid = (left + right) / 2
```

Знаходиться середина поточного проміжку.

---

```python
p = probability(N, m, T, t1, mid)
```

Обчислюється ймовірність встигнути, якщо прийти за `mid` часу до моменту `T`.

---

```python
if p >= 0.9:
```

Перевіряється, чи достатня ймовірність.

Якщо ймовірність не менше 90%, то цей час підходить.

---

```python
right = mid
```

Якщо `mid` підходить, пробуємо знайти ще менший час.

Тому права межа зсувається вліво.

---

```python
else:
    left = mid
```

Якщо ймовірність менша за 90%, то `mid` недостатній.

Потрібно приходити раніше, тобто збільшити `x`.

Тому ліва межа зсувається вправо.

---

```python
return right
```

Повертається знайдений мінімальний час приходу.

# Основна частина програми

```python
N = int(input("Кількість глядачів N: "))
```

Користувач вводить кількість глядачів.

`input()` зчитує текст.

`int()` перетворює його на ціле число.

---

```python
m = int(input("Кількість турнікетів m: "))
```

Користувач вводить кількість турнікетів.

---

```python
T = float(input("За скільки часу відкривають турнікети T: "))
```

Користувач вводить час `T`.

`float()` дозволяє вводити дробові числа.

---

```python
t1 = float(input("Максимальний час проходу t1: "))
```

Користувач вводить максимальний час проходження через турнікет.

---

```python
result = find_min_time(N, m, T, t1)
```

Запускається пошук мінімального часу приходу.

Результат зберігається у змінну `result`.

---

```python
print("\nМінімальний час приходу:")
```

Виводиться заголовок результату.

---

```python
print(round(result, 2))
```

Виводиться знайдений час, округлений до 2 знаків після коми.

---

```python
final_probability = probability(N, m, T, t1, result)
```

Для знайденого часу ще раз обчислюється фінальна ймовірність.

---

```python
print("Ймовірність пройти:")
```

Виводиться підпис для ймовірності.

---

```python
print(round(final_probability, 4))
```

Виводиться ймовірність, округлена до 4 знаків після коми.

# Підсумок

Програма відповідає на питання:

> За скільки часу до початку потрібно прийти нашому глядачу, щоб з імовірністю не менше 90% пройти через турнікети?

Для цього вона:

1. Створює одного нашого глядача.
2. Генерує інших випадкових глядачів.
3. Сортує всіх за часом приходу.
4. Моделює роботу турнікетів.
5. Перевіряє, чи наш глядач встиг.
6. Повторює це багато разів.
7. Знаходить мінімальний потрібний час приходу.
