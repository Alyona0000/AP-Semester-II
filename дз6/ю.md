Завдання 1. Аналіз JSON з інформацією про курси
Є JSON-рядок з інформацією про навчальні курси:
courses_json = '''
[
{
"title": "Python Basics",
"teacher": "Koval",
"hours": 36,
"students": ["Anna", "Bohdan", "Iryna"],
"active": true
},
{
"title": "Data Analysis",
"teacher": "Petrenko",
"hours": 42,
"students": ["Maksym", "Olha"],
"active": true
},
{
"title": "Web Scraping",
"teacher": "Ivanenko",
"hours": 24,
"students": ["Taras", "Anna", "Olha", "Roman"],
"active": false
}
]
'''
Потрібно перетворити JSON-рядок у Python-об’єкт, вивести назви всіх курсів, вивести
тільки активні курси, для кожного курсу показати кількість студентів, знайти курс з
найбільшою кількістю студентів і порахувати загальну кількість годин тільки для
активних курсів.

Завдання 2. Створення JSON-файлу зі звітом
На основі даних із першого завдання потрібно створити нову структуру даних у вигляді
списку словників:
[
{

"title": "...",
"teacher": "...",
"students_count": ...,
"active": ...
}
]
Потрібно сформувати цей список, записати його у файл courses_report.json з гарним
форматуванням через indent=4 та ensure_ascii=False. Після цього потрібно зчитати файл
назад через json.load() і вивести прочитані дані на екран.

Завдання 3. Аналіз XML з інформацією про бібліотеку
Є XML-рядок з інформацією про книги:
library_xml = """
<library>
<book id="1" category="programming">
<title>Python Basics</title>
<author>John Smith</author>
<year>2020</year>
<pages>350</pages>
</book>
<book id="2" category="statistics">
<title>Statistics for Beginners</title>
<author>Anna Brown</author>
<year>2018</year>
<pages>280</pages>
</book>
<book id="3" category="programming">
<title>Advanced Python</title>
<author>Kate Wilson</author>
<year>2023</year>
<pages>500</pages>
</book>
</library>
"""
Потрібно прочитати XML-рядок за допомогою ET.fromstring(), вивести кореневий тег
документа, вивести назви всіх книг, для кожної книги показати її id, category, title,
author, year і pages. Окремо потрібно вивести тільки книги з категорією programming, а
також знайти середню кількість сторінок у книгах.

Завдання 4. Створення XML-документа
Потрібно створити XML-документ з інформацією про студентів за допомогою
ET.Element() та ET.SubElement().
Приклад структури:
<students> <student group="ST-21"> <name>Anna</name> <age>20</age>
<grade>95</grade> </student> <student group="ST-22"> <name>Bohdan</name>
<age>21</age> <grade>82</grade> </student> </students>
Потрібно створити кореневий елемент students, додати не менше трьох студентів, для
кожного студента додати атрибут group і вкладені теги name, age, grade. Створений XML
потрібно перетворити у рядок через ET.tostring(..., encoding="unicode"), вивести на
екран, записати у файл students.xml, після цього прочитати файл назад через ET.parse() і
вивести імена всіх студентів.
