# 6. Верхня частина рамки

```python
print("╔" + "═" * 58 + "╗")
```

Цей рядок виводить верхню межу рамки.

Розберемо його по частинах.

```python
"╔"
```

Це символ лівого верхнього кута рамки.

```python
"═" * 58
```

Це означає: повторити символ `═` 58 разів.

У Python оператор `*` для рядка означає повторення.

Наприклад:

```python
"═" * 5
```

дасть:

```text
═════
```

```python
"╗"
```

Це символ правого верхнього кута рамки.

Увесь рядок:

```python
"╔" + "═" * 58 + "╗"
```

з’єднує ці частини разом.

У результаті буде виведено:

```text
╔══════════════════════════════════════════════════════════╗
```

# 27. Перевірка способу запуску файлу

```python
if __name__ == '__main__':
```

Це спеціальна конструкція Python.

Змінна:

```python
__name__
```

зберігає назву поточного модуля.

Якщо файл запускається напряму, Python встановлює:

```python
__name__ = '__main__'
```

Тому умова:

```python
if __name__ == '__main__':
```

означає:

```text
якщо цей файл запущено напряму, тоді виконай код нижче
```

Наприклад, якщо ми запускаємо:

```bash
python main.py
```

то ця умова спрацює.

Але якщо цей файл просто імпортувати в інший файл:

```python
import main
```

то функція `main()` автоматично не запуститься.

Це дуже корисно, бо дозволяє контролювати запуск програми.

# 31. Можлива помилка

Якщо у файлі `task1.py` немає функції `main()`, тоді рядок:

```python

```

викличе помилку:

```text
AttributeError: module 'task1' has no attribute 'main'
```

Це означає:

```text
у модулі task1 немає функції main
```

Щоб виправити помилку, треба додати у файл `task1.py`:

```python
def main():
    ...
```
