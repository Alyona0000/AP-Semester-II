# AP Semester II - Домашнє завдання 5

## Структура проекту

Python рішення 4 алгоритмічних задач:

- **task1.py** - Розклад пар
- **task2.py** - Підбір команди  
- **task3.py** - Перевірка маршруту
- **task4.py** - Жадібний алгоритм vs Повний перебір
- **main.py** - Головна програма, що запускає всі завдання

## Запуск

Запустити одне завдання:
```bash
python task1.py
python task2.py
python task3.py
python task4.py
```

Запустити все разом:
```bash
python main.py
```

## Результати

### Завдання 1: Розклад пар
- **Завдання:** Розмістити 3 предмети (Python, Math, Statistics) по 5 часових слотів
- **Обмеження:** 
  - Python не може бути в слоті 1
  - Math не може стояти одразу після Statistics
- **Результат:** Знайдено 39 допустимих розкладів. Перші 10 виведені.

### Завдання 2: Підбір команди
- **Завдання:** Знайти найменшу команду, яка покриває всі необхідні навички
- **Дані:** 5 кандидатів з різними навичками, 4 необхідні навички
- **Результат:** Мінімальна команда з 2 осіб (Bohdan + Iryna)

### Завдання 3: Перевірка маршруту
- **Завдання:** Перевірити коректність маршруту у графі
- **Граф:** 5 аудиторій (A, B, C, D, E), 10 допустимих переходів
- **Результат:** Протестовано 6 маршрутів - 4 валідні, 2 невалідні

### Завдання 4: Жадібний алгоритм vs Повний перебір
- **Завдання:** Задача про здачу - монети {1, 3, 4}, цільова сума 6
- **Результат:** 
  - Жадібний алгоритм: [4, 1, 1] = 3 монети
  - Оптимальний (повний перебір): [3, 3] = 2 монети
  - **Висновок:** Жадібний алгоритм НЕ завжди оптимальний
