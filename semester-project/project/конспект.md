# Пояснення коду складського веб-додатку

## Загальна інформація

Даний проєкт являє собою веб-додаток для обліку товарів на складі. Програма написана мовою Python з використанням фреймворку Flask та бази даних SQLite.

Основні можливості системи:

* зберігання товарів;
* робота з категоріями;
* облік партій товару;
* пошук товарів;
* контроль місць зберігання;
* оформлення накладних;
* експорт накладних у формат Word.

---

# Імпорт бібліотек

```python
from flask import Flask, render_template, request, jsonify, send_file
```

Flask використовується для створення веб-сервера та обробки HTTP-запитів.

```python
from flask_sqlalchemy import SQLAlchemy
```

SQLAlchemy забезпечує роботу з базою даних через об'єктно-орієнтований підхід.

```python
from datetime import datetime
```

Необхідний для роботи з датою та часом.

```python
import os
```

Використовується для роботи зі шляхами до файлів.

```python
from io import BytesIO
```

Дозволяє створювати файли в оперативній пам'яті.

```python
from docx import Document
```

Створення Word-документів.

---

# Створення Flask-додатку

```python
app = Flask(__name__)
```

Створюється екземпляр веб-додатку.

---

# Налаштування бази даних

```python
basedir = os.path.abspath(os.path.dirname(__file__))
```

Отримання абсолютного шляху до папки проєкту.

```python
app.config["SQLALCHEMY_DATABASE_URI"]
```

Вказує шлях до бази даних SQLite.

```python
db = SQLAlchemy(app)
```

Створення об'єкта для роботи з базою даних.

---

# Модель Category

```python
class Category(db.Model):
```

Описує таблицю категорій.

Поля:

* id — ідентифікатор;
* name — назва категорії.

Приклади категорій:

* Техніка;
* Ліки;
* Одяг;
* Канцелярія.

---

# Модель Product

```python
class Product(db.Model):
```

Описує товари.

Поля:

* id;
* name;
* category_id;
* unit;
* price.

Приклад товару:

* iPhone 15;
* Парацетамол;
* Ноутбук ASUS.

# Метод total_quantity()

```python
def total_quantity(self):
```

Обчислює сумарну кількість товару на складі.

Принцип роботи:

Програма проходить по всіх партіях товару та додає їх кількість.

Наприклад:

Партія 1 = 20

Партія 2 = 15

Результат:

35 одиниць.

```python
db.session.add(...)
```

# Функція add_product_if_missing()

Створює товар.

Перевіряє:

* чи існує товар;
* чи існує категорія.

Після цього додає товар до бази.

---

# Функція add_batch_if_missing()

Створює партію товару.

Перед додаванням перевіряється:

* наявність товару;
* унікальність номера партії;
* вільне місце на складі.

# API статистики

```python
@app.route("/api/stats")
```

* партій;

* накладних.

# API категорій

```python
@app.route("/api/categories")
```

Можливості:

GET:

отримати список категорій.

POST:

створити нову категорію.

---

# API товарів

```python
@app.route("/api/products")
```

Можливості:

* додавання товарів;
* пошук за назвою;
* фільтрація за категорією.

---

# API місць зберігання

```python
@app.route("/api/storage")
```

* місткість;
* зайняте місце;
* вільне місце.

---

# API партій

```python
@app.route("/api/batches")
```

Дозволяє:

* додавати нові партії;
* переглядати існуючі.

---

# API відпуску товару

```python
@app.route("/api/release")
```

Працює так:

1. Обирається партія.
2. Вказується кількість.
3. Вказується одержувач.
4. Створюється накладна.
5. Кількість товару зменшується.

---

# API накладних

```python
@app.route("/api/invoices")
```

Повертає список усіх створених накладних.

---

# Формування Word-файлу

```python
@app.route("/api/invoice/<id>/download")
```

Створюється документ Word.

Містить:

* номер накладної;
* дату;
* товар;
* кількість;
* суму;
* постачальника;
* одержувача.

Після цього файл автоматично завантажується користувачу.
