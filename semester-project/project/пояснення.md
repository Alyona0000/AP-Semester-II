# Blue Stock — веб-додаток для управління складом

## Опис проєкту

**Blue Stock** — це веб-додаток для моделювання роботи складу. Програма дозволяє вести облік товарів, категорій, партій товару, місць зберігання, залишків на складі, а також оформлювати відпуск товару зі створенням накладної у форматі **MS Word**.

Роботу виконала: **Рибакова Альона Олексіївна**
Спеціальність: **Статистика**
Курс: **1 курс, 2 семестр**

---

## Завдання

Потрібно скласти програму, що працює в оточенні вебсервера та реалізує функціональність роботи складу.

У програмі реалізовано:

* зберігання інформації про товари в базі даних;
* поділ товарів за категоріями;
* зберігання партій товарів;
* прив’язка кожної партії до конкретного місця зберігання;
* пошук товару за категорією;
* пошук товару за частиною назви;
* перегляд залишку певного товару на складі;
* перегляд місця зберігання кожної партії;
* приймання товарів на склад;
* відпуск товару зі складу;
* формування накладної у форматі `.docx`.

## База даних

У базі даних створюються такі таблиці:

* `Category` — категорії товарів;

## Модель `Category`

Модель `Category` відповідає за категорії товарів.

```python
class Category(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(120), unique=True, nullable=False)
    products = db.relationship("Product", backref="category", lazy=True)
```

Поля моделі:

* `id` — унікальний номер категорії;
* `name` — назва категорії;
* `products` — зв’язок із товарами, які належать до цієї категорії.

Приклади категорій:

* Електроніка;
* Комп'ютерна техніка;
* Одяг;
* Меблі;
* Канцелярія;
* Харчові продукти.

---

## Модель `Product`

Модель `Product` відповідає за товари на складі.

```python
class Product(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(200), nullable=False)
    category_id = db.Column(db.Integer, db.ForeignKey("category.id"), nullable=False)
    unit = db.Column(db.String(50), default="шт")
    price = db.Column(db.Float, default=0)
```

Поля моделі:

* `id` — унікальний номер товару;
* `name` — назва товару;
* `category_id` — номер категорії;
* `unit` — одиниця виміру;
* `price` — ціна товару.

У моделі також є метод:

```python
def total_quantity(self):
    return sum(b.quantity for b in self.batches)
```

Цей метод рахує загальний залишок товару на складі, додаючи кількість з усіх партій цього товару.

---

## Модель `Storage`

Модель `Storage` відповідає за місця зберігання товарів.

```python
class Storage(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    building = db.Column(db.String(50), nullable=False)
    department = db.Column(db.String(50), nullable=False)
    shelf = db.Column(db.String(50), nullable=False)
    capacity = db.Column(db.Integer, default=1000)
    current_quantity = db.Column(db.Integer, default=0)
```

Поля моделі:

* `id` — унікальний номер місця зберігання;
* `building` — корпус;
* `department` — відділення;
* `shelf` — полиця;
* `capacity` — максимальна місткість;
* `current_quantity` — поточна зайнятість.

Метод:

```python
def address(self):
    return f"Корпус {self.building}, відділення {self.department}, полиця {self.shelf}"
```

повертає повну адресу місця зберігання.

---

## Модель `Batch`

Модель `Batch` відповідає за партії товарів.

```python
class Batch(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    product_id = db.Column(db.Integer, db.ForeignKey("product.id"), nullable=False)
    storage_id = db.Column(db.Integer, db.ForeignKey("storage.id"), nullable=False)
    quantity = db.Column(db.Integer, nullable=False)
    batch_number = db.Column(db.String(100), unique=True, nullable=False)
    supplier = db.Column(db.String(200), default="")
    receipt_date = db.Column(db.DateTime, default=datetime.utcnow)
```

Поля моделі:

* `id` — унікальний номер партії;
* `product_id` — товар, до якого належить партія;
* `storage_id` — місце зберігання партії;
* `quantity` — кількість товару в партії;
* `batch_number` — номер партії;
* `supplier` — постачальник;
* `receipt_date` — дата надходження партії.

Кожна партія пов’язана з конкретним товаром і конкретним місцем зберігання.

---

## Модель `Invoice`

Модель `Invoice` відповідає за накладні на відпуск товару.

```python
class Invoice(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    batch_id = db.Column(db.Integer, db.ForeignKey("batch.id"), nullable=False)
    invoice_number = db.Column(db.String(100), unique=True, nullable=False)
    quantity_released = db.Column(db.Integer, nullable=False)
    recipient = db.Column(db.String(200), default="")
    release_date = db.Column(db.DateTime, default=datetime.utcnow)
```

Поля моделі:

* `id` — унікальний номер накладної;
* `batch_id` — партія, з якої відпущено товар;
* `invoice_number` — номер накладної;
* `quantity_released` — кількість відпущеного товару;
* `recipient` — одержувач;
* `release_date` — дата відпуску.

### `/api/stats`

Маршрут повертає статистику складу:

@app.route("/api/stats")
def api_stats():
    return jsonify({

        "storage": Storage.query.count(),
        "invoices": Invoice.query.count()

Ця інформація показується у верхніх картках інтерфейсу.

## Робота з категоріями

Маршрут:

```text
/api/categories
```

підтримує два методи:

* `GET` — отримати список категорій;
* `POST` — додати нову категорію.

Коли користувач додає категорію, JavaScript надсилає POST-запит на сервер. Сервер перевіряє, чи не порожня назва і чи такої категорії ще немає в базі.

Якщо все правильно, категорія додається в базу даних.

## Робота з товарами

Маршрут:

```text
/api/products
```

підтримує:

* `GET` — отримати список товарів;
* `POST` — додати новий товар.

Під час додавання товару користувач вводить:

* назву товару;
* категорію;
* одиницю виміру;
* ціну.

Після натискання кнопки **«Додати товар»** JavaScript надсилає дані на сервер. Сервер створює новий об’єкт `Product` і записує його в базу даних.

## Пошук товарів

Пошук товарів реалізовано через параметри запиту:

```text
/api/products?search=комп
```

або:

```text
/api/products?category_id=2
```

Також можна поєднувати обидва фільтри:

```text
/api/products?search=комп&category_id=2
```

У коді це працює так:

```python
if search:
    query = query.filter(Product.name.ilike(f"%{search}%"))

if category_id:
    query = query.filter(Product.category_id == int(category_id))
```

Тобто програма може знайти товар за частиною назви та за категорією.

Маршрут:

```text
/api/storage
```

повертає список усіх місць зберігання.

Для кожного місця показується:

* адреса;

* скільки вже зайнято;
* скільки ще вільно.

Це дозволяє контролювати, чи є місце для нової партії товару.

## Приймання партії товару

Приймання товару на склад виконується через маршрут:

```text
/api/batches
```

Метод `POST` додає нову партію товару.

Користувач вказує:

* товар;
* місце зберігання;
* кількість;
* номер партії;
* постачальника.

Перед додаванням партії сервер перевіряє:

* чи існує товар;
* чи існує місце зберігання;
* чи кількість більша за нуль;
* чи введено номер партії;
* чи не існує вже партія з таким номером;
* чи достатньо вільного місця на складі.

Якщо всі перевірки успішні, партія додається до бази, а зайнятість місця зберігання збільшується.

* постачальника;

Таким чином можна побачити не тільки загальний залишок товару, а й де саме зберігається кожна партія.

## Відпуск товару зі складу

Відпуск товару виконується через маршрут:

```text

```

Користувач обирає партію, вводить кількість і одержувача.

Сервер перевіряє:

Після цього кількість у партії зменшується, зайнятість місця зберігання також зменшується, а в базі створюється накладна.

## JavaScript-запити до сервера

Для отримання даних використовується функція:

```javascript
async function requestJSON(url, options = {})
```

Вона виконує `fetch`-запит до сервера, отримує відповідь у форматі JSON і перевіряє, чи не виникла помилка.

Наприклад, для отримання товарів викликається:

```javascript
const products = await requestJSON(`${API}/api/products`);
```

Оскільки у коді написано:

```javascript
const API = "";
```

запити надсилаються на той самий сервер, з якого відкрито сторінку.

---

## Чому не можна відкривати `index.html` напряму

Якщо відкрити файл `index.html` подвійним кліком, браузер відкриє його як звичайний файл. У такому випадку JavaScript не зможе нормально звертатися до Flask-сервера, і може з’явитися помилка:

```text
Failed to fetch
```

Тому сторінку потрібно відкривати тільки через Flask:

```text
http://127.0.0.1:5000
```

## Як працює додавання товару

Користувач вводить назву товару, вибирає категорію, вказує одиницю виміру і ціну.

Після натискання кнопки JavaScript викликає функцію:

```javascript
addProduct()
```

Вона збирає дані з форми та надсилає POST-запит на сервер. Сервер створює товар у базі даних. Після цього таблиця товарів оновлюється, і новий товар з’являється у списку.

---

## Як працює пошук

Пошук можна виконати двома способами:

1. через верхнє поле пошуку;
2. через форму у вкладці **Товари**.

Якщо користувач вводить частину назви, програма шукає всі товари, у назві яких є цей текст.

Наприклад, якщо ввести:

```text
комп
```

програма може знайти:

```text
комп'ютер
комплект
комплектуючі
```

Також можна обрати категорію. Тоді програма покаже тільки товари з вибраної категорії.

---

## Як працює приймання партії

Спочатку потрібно створити товар. Потім у вкладці **Партії** обрати цей товар, місце зберігання, ввести кількість, номер партії та постачальника.

Після додавання партії залишок товару збільшується. Наприклад, якщо товар мав залишок `0`, а на склад прийняли партію на `50` одиниць, то залишок товару стане `50`.

---

## Як працює відпуск товару

У вкладці **Відпуск** користувач обирає партію, з якої потрібно забрати товар, вказує кількість і одержувача.

Після оформлення відпуску:

* кількість у партії зменшується;
* загальний залишок товару зменшується;
* створюється накладна;
* накладну можна завантажити у форматі Word.

## Можливі помилки

### `Failed to fetch`

Ця помилка означає, що сторінка не може підключитися до сервера.

Щоб виправити:

1. запустити сервер командою:

```bash
python app.py
```

2. відкрити сторінку через:

```text
http://127.0.0.1:5000
```

### Порожній список категорій

Якщо категорії не відображаються, потрібно перевірити, чи запущений сервер. Також можна видалити файл `warehouse.db` і запустити програму заново. Після цього початкові категорії створяться автоматично.

### Товар не з’являється у списку

Можлива причина — активний пошук або вибрана категорія. Після додавання товару програма очищає фільтри, щоб новий товар одразу відображався у таблиці.

## Висновок

У результаті було створено веб-додаток для управління складом. Програма дозволяє зберігати інформацію про товари, категорії, партії та місця зберігання у базі даних. Користувач може додавати товари, приймати партії на склад, шукати товари за назвою або категорією, переглядати залишки, оформлювати відпуск товару та створювати накладні у форматі Microsoft Word.

Таким чином, програма виконує основні вимоги завдання та моделює роботу складу в середовищі вебсервера.
