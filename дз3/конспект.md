# Пояснення коду клієнта чату

## Загальне призначення програми

Даний файл реалізує клієнтську частину мережевого чату.

Програма підключається до сервера через TCP-з'єднання та дозволяє:

* надсилати повідомлення;
* отримувати повідомлення від інших користувачів;
* виконувати команди сервера;
* працювати одночасно на прийом і передачу повідомлень за допомогою потоків.

Для роботи програми необхідно, щоб сервер був запущений на адресі:

```text
127.0.0.1:5000
```

---

# Імпорт бібліотек

```python
import socket
```

Імпортується модуль `socket`.

Він використовується для створення мережевих з'єднань між комп'ютерами.

Саме через сокети клієнт підключається до сервера.

---

```python
import threading
```

Імпортується модуль для роботи з потоками.

Потік (Thread) дозволяє виконувати декілька задач одночасно.

У даній програмі один потік:

* отримує повідомлення від сервера,

а другий:

* надсилає повідомлення серверу.

---

```python
import sys
```

Імпортується системний модуль Python.

Використовується для завершення роботи програми через:

```python
sys.exit()
```

---

# Константи програми

```python
HOST = "127.0.0.1"
```

Змінна HOST містить IP-адресу сервера.

Адреса:

```text
127.0.0.1
```

називається localhost.

Вона означає:

```text
цей самий комп'ютер
```

Тобто клієнт підключається до сервера, який працює на цьому ж ПК.

---

```python
PORT = 5000
```

Номер порту сервера.

Порт можна уявити як двері, через які клієнт заходить до сервера.

У даному випадку використовується порт:

```text
5000
```

---

# Функція receive_messages()

```python
def receive_messages(sock):
```

Створюється функція для прийому повідомлень від сервера.

Параметр:

```python
sock
```

це сокет, через який встановлено з'єднання із сервером.

---

```python
file = sock.makefile("r", encoding="utf-8")
```

Сокет перетворюється на файловий об'єкт.

Це дозволяє читати повідомлення так само, як рядки з файлу.

Параметри:

```python
"r"
```

означає режим читання.

```python
encoding="utf-8"
```

дозволяє коректно працювати з українськими літерами.

---

```python
try:
```

Початок блоку обробки помилок.

Якщо під час роботи виникне помилка, програма не завершиться аварійно.

---

```python
for line in file:
```

Цикл читає повідомлення від сервера.

Кожен рядок відповідає одному повідомленню.

Наприклад:

```text
Привіт
```

```text
Як справи?
```

---

```python
print(line.rstrip("\n"))
```

Отримане повідомлення виводиться на екран.

Метод:

```python
rstrip("\n")
```

видаляє символ переходу на новий рядок.

Було:

```text
Привіт\n
```

Стало:

```text
Привіт
```

---

```python
except:
    pass
```

Якщо сталася помилка (наприклад сервер відключився), програма просто переходить далі.

---

```python
print("З'єднання з сервером закрито")
```

Виводиться повідомлення:

```text
З'єднання з сервером закрито
```

---

```python
sys.exit()
```

Повністю завершує програму.

---

# Функція send_messages()

```python
def send_messages(sock):
```

Функція відповідає за відправлення повідомлень на сервер.

---

```python
while True:
```

Нескінченний цикл.

Клієнт постійно чекає введення користувача.

---

```python
text = input()
```

Зчитується повідомлення, введене користувачем.

Наприклад:

```text
Привіт усім
```

або

```text
/list
```

---

```python
sock.sendall((text + "\n").encode("utf-8"))
```

```python
text + "\n"
```

```python

```

перетворює текст у байти.

Після цього:

```python
sendall(...)
```

відправляє дані через мережу.


Якщо користувач ввів:

```text
/quit
```

то клієнт завершує роботу.

---

```python
break
```

Перериває цикл.

---

```python
except:
    break
```

Якщо під час відправки сталася помилка, цикл також завершується.

---

```python
sock.close()
```

Тобто розриває мережеве з'єднання із сервером.

# Функція main()

```python
def main():
```

Головна функція програми.

Саме вона запускає весь клієнт.

---

```python
sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
```

Створюється TCP-сокет.

Параметр:

```python
socket.AF_INET
```

означає IPv4.

Параметр:

```python
socket.SOCK_STREAM
```

означає TCP-протокол.

---

```python
sock.connect((HOST, PORT))
```

Встановлюється з'єднання із сервером.

Фактично клієнт підключається до:

```text
127.0.0.1:5000
```

---

```python
print("Підключено до сервера")
```

Повідомлення про успішне підключення.

---

```python
print("Введіть команду або повідомлення:")
```

Запрошення до введення тексту.

---

```python
receive_thread = threading.Thread(
    target=receive_messages,
    args=(sock,),
    daemon=True
)
```

Створюється потік для отримання повідомлень.

Параметр:

```python
target=receive_messages
```

вказує функцію, яку буде виконувати потік.

---

```python
send_thread = threading.Thread(
    target=send_messages,
    args=(sock,)
)
```

Створюється другий потік.

Він відповідає за відправлення повідомлень.

---

```python
receive_thread.start()
```

Запуск потоку прийому повідомлень.

---

```python
send_thread.start()
```

Запуск потоку надсилання повідомлень.

Тепер обидва потоки працюють одночасно.

---

```python
send_thread.join()
```

Головний потік чекає завершення потоку відправки.

Програма не завершиться, поки користувач не вийде з чату.

---

# Принцип роботи програми

1. Створюється TCP-з'єднання.
2. Клієнт підключається до сервера.
3. Запускається потік прийому повідомлень.
4. Запускається потік відправки повідомлень.
5. Користувач вводить текст.
6. Повідомлення надсилається серверу.
7. Сервер розсилає повідомлення іншим клієнтам.
8. Клієнт отримує повідомлення та виводить їх на екран.
9. При введенні команди `/quit` клієнт завершує роботу.
